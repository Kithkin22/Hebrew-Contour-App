    Use this to mark matching start/end phrases, like an inclusio. Select a word, set start, select the ending word, then set end.

    Contour editing

    KeyAction
    EnterBreak clause at selected word (last clause of a verse continues into the next verse)
    Tab / BackspaceIndent / outdent clause (Backspace on the first clause of a verse joins it with the previous verse)
    nAdd or edit a word note
    tAdd or edit a gloss (translation)
    p / sToggle predicate / subject marking
    Delete / Shift+BackspaceHide or restore selected word
    Arrow keysNavigate words and clauses (RTL-aware)
    Ctrl+Shift + b / i / u / c / hApply bold / italic / underline / text color / highlight to all matching words (same surface form as selection, current passage)
    Ctrl+Shift + DeleteHide or restore all matching words
